# Network Security Monitoring & Traffic Analysis Lab

## 📌 Project Overview

This project demonstrates practical network security monitoring and traffic analysis using a controlled Kali Linux laboratory environment.

Network traffic was captured and analyzed using Wireshark, while Nmap and DNS utilities were used for basic network and DNS analysis.

## 🎯 Objectives

- Understand basic network configuration and routing
- Perform basic network port scanning using Nmap
- Analyze DNS queries and responses
- Capture and analyze network packets using Wireshark
- Study TCP, UDP and TLS traffic
- Analyze TCP connection attempts
- Examine network conversations and endpoints
- Identify normal network traffic patterns and security observations

## 🛠️ Tools & Technologies

- Kali Linux
- VMware
- Wireshark
- Nmap
- dig
- GitHub

## 🔬 Methodology

1. Configured the Kali Linux network interface.
2. Identified the default gateway and routing information.
3. Performed a basic Nmap scan on the lab machine.
4. Performed DNS analysis using `dig`.
5. Captured network traffic using Wireshark.
6. Analyzed DNS, TCP, UDP and TLS traffic.
7. Examined TCP SYN connection attempts.
8. Analyzed protocol hierarchy and network conversations.
9. Analyzed IPv4 endpoints.
10. Saved the captured traffic as a PCAPNG evidence file.

## 📊 Traffic Analysis

The captured traffic included protocols such as:

- TCP
- UDP
- DNS
- TLS
- NTP
- ARP
- QUIC

The analysis helped identify communication patterns, protocols, ports and network endpoints.

## 🔐 Security Findings

The captured traffic was primarily consistent with normal network and web communication.

TCP connections, DNS queries, UDP traffic and TLS-encrypted communication were observed.

No malicious activity was concluded solely from this capture. The project demonstrates the process of collecting network evidence and analyzing traffic for potentially unusual patterns.
